# SonosLibra – Site Node Provisioning (v5.4)

ชุดสคริปต์ติดตั้งเครื่อง Mini PC (Windows) สำหรับไซต์งาน ให้พร้อมใช้งาน 24/7 และให้ทีมรีโมทเข้ามาได้ผ่าน **Tailscale (VPN) + RustDesk**

> เอกสารนี้สำหรับทีมงานและคนที่มารับช่วงต่อ อ่านให้จบก่อนออกไปติดตั้งที่ไซต์ครั้งแรก

---

## 1. ไฟล์ในชุดนี้

```
USB:\
├── Install-SiteNode.bat     ← ดับเบิลคลิกไฟล์นี้ไฟล์เดียว
├── Setup-SiteNode.ps1       ← สคริปต์หลัก (.bat จะเรียกให้เอง)
├── README.md                ← เอกสารนี้
│
│   --- ไฟล์ที่สคริปต์สร้างขึ้นเอง ---
├── Logs\
│   ├── Setup-v5.4-<วันเวลา>-<ชื่อเครื่อง>.log
│   └── Sticker_<ชื่อเครื่อง>.txt          ← ข้อความสำหรับพิมพ์สติกเกอร์
└── Site_Inventory_Backup.csv               ← สำรองข้อมูลเครื่อง
```

| ไฟล์นอก USB | ใช้ที่ไหน |
|---|---|
| `tailscale-acl.hujson` | Tailscale Admin Console → Access controls (วางทับทั้งไฟล์ ตั้งครั้งเดียว) |
| `Code.gs` | Google Apps Script ของชีต Inventory (v3.2 จองเลขลำดับด้วย LockService) อัปเดตผ่าน **Manage deployments → Edit → New version** ห้ามกด New deployment เพราะ URL จะเปลี่ยน |
| `.vscode/settings.json`, `.gitattributes` | โฟลเดอร์โปรเจกต์ใน VS Code / Git |

## 2. สิ่งที่ต้องพร้อมก่อน (ผู้ดูแลตั้งครั้งเดียว)

- [ ] **Tailscale ACL** วางทับด้วย `tailscale-acl.hujson`
  - Tailnet `sonoslibra-engineering.github` ใช้ **บัญชี GitHub ของทีมร่วมกัน** บัญชีเดียว
  - ACL ใช้ `autogroup:member` จึงไม่ต้องใส่ชื่อคน
- [ ] **OAuth client** ที่ฝังในสคริปต์อยู่ใน tailnet นี้, scope = **Auth Keys (Write)**, tag = `tag:site-node`
- [ ] **Google Apps Script** (Webhook) ยังเปิดใช้งาน
- [ ] โน้ตบุ๊กของทีมติดตั้ง **Tailscale** (login บัญชี GitHub ของทีม) และ **RustDesk**

## 3. ขั้นตอนติดตั้งที่ไซต์

1. เปิด Mini PC แล้ว login ด้วยบัญชี Administrator ใดก็ได้ (สคริปต์จะสร้างบัญชี `SiteNode` สำหรับ Auto-Login ให้เอง)
2. ต่ออินเทอร์เน็ตด้วยสาย LAN หรือ Wi-Fi
3. เสียบ USB แล้วดับเบิลคลิก **`Install-SiteNode.bat`** จากนั้นกด **Yes** ที่ UAC
4. ถ้าระบบดึงเลขลำดับจาก Cloud ไม่ได้ จะให้**พิมพ์เลขลำดับเอง** ให้ดูเลขล่าสุดใน Google Sheets แล้วพิมพ์เลขถัดไป
5. พิมพ์ **ชื่อสถานที่ภาษาอังกฤษ ยาว 2–9 ตัวอักษร** เช่น `ICONSIAM`, `PARAGON` หรือชื่อย่อ เช่น `CTW` แล้วกด Enter
6. รอ 3–5 นาที
   - **สำเร็จ** จะขึ้นกรอบสีเขียว ให้ทำสติกเกอร์จากข้อมูลบนจอหรือไฟล์ `Logs\Sticker_*.txt` เครื่องจะ Restart เองหลัง 15 วินาที แล้วถอด USB ได้
   - **ไม่สำเร็จ** จะขึ้นกรอบสีแดงพร้อมสาเหตุ เครื่องจะ**ไม่** Restart ให้แก้ตามคำแนะนำแล้ว**รันใหม่ได้เลย**
7. หลัง Restart เครื่องต้อง **Login เข้าบัญชี `SiteNode` เอง**
8. **ก่อนออกจากไซต์** ให้ทดสอบรีโมทเข้าเครื่องด้วย RustDesk ผ่าน `100.x` (ดูหัวข้อ 6)

> ❗ **ห้ามทิ้งเครื่องไว้ที่ไซต์ถ้ายังไม่เห็นกรอบสีเขียว**

## 4. การตั้งชื่อเครื่อง

| | รูปแบบ | ตัวอย่าง | ใช้ที่ |
|---|---|---|---|
| **ชื่อเครื่อง (Device)** | `YY-ลำดับ-สถานที่` (ไม่เกิน 15 ตัว) | `26-07-ICONSIAM` | Windows, Tailscale, สติกเกอร์ |
| **ทะเบียน (SiteName)** | `YYYY-ลำดับ-สถานที่` | `2026-07-ICONSIAM` | คอลัมน์ SiteName ใน Google Sheets (Apps Script ใช้นับเลขลำดับ) |

- ชื่อ Windows, ชื่อ Tailscale และสติกเกอร์**ตรงกันเสมอ** ไม่มีการตัดชื่อ
- ชื่อสถานที่ยาวได้ไม่เกิน **9 ตัว** (หรือ 8 ตัวถ้าเลขลำดับมี 3 หลัก) ถ้ายาวกว่านี้ระบบจะให้พิมพ์ชื่อย่อใหม่
- **ติดตั้งเครื่องทดแทนโดยใช้ชื่อเดิม:** พิมพ์ชื่อเต็ม เช่น `26-07-ICONSIAM` แทนการพิมพ์แค่ชื่อสถานที่

## 5. สคริปต์ทำอะไรบ้าง

| ขั้น | รายละเอียด |
|---|---|
| ตรวจก่อนเริ่ม | สิทธิ์ Admin, ต่อ HTTPS ไป Tailscale ได้, **ไม่มี winget → ติดตั้ง winget ให้อัตโนมัติ** |
| ตั้งชื่อ | ดึงเลขลำดับจาก Google Sheets (ลอง 3 ครั้ง ถ้าไม่ได้ให้พิมพ์เอง) |
| 1/7 Power | High Performance, ไม่หลับ, ไม่ดับจอ, ปิด USB/PCIe/NIC power saving, ปุ่ม Power = ไม่ทำอะไร |
| 2/7 บัญชี | สร้างบัญชี Local **`SiteNode`** (Admin, รหัสไม่หมดอายุ) + Auto-Login + ปิด Screen Saver |
| 3/7 ระบบ | Time zone ไทย, **Windows Update ติดตั้งอาทิตย์ 03:00, Reboot อาทิตย์ 04:00** |
| 4/7 ติดตั้ง | Tailscale + RustDesk **เวอร์ชันล่าสุดเสมอ** (winget → ถ้าไม่ได้ดาวน์โหลด MSI จากเว็บทางการ + ตรวจลายเซ็นดิจิทัล → ตรวจว่ามีไฟล์จริง) ถ้าติดตั้งอยู่แล้วจะอัปเดตเป็นเวอร์ชันล่าสุด |
| 5/7 RustDesk | ตั้งรหัสผ่าน, เปิด Direct IP, Firewall รับเฉพาะจาก Tailscale (100.64.0.0/10) |
| 6/7 Tailscale | Join ด้วย `tag:site-node` (ไม่มีวันหมดอายุ) **ถ้าไม่ได้ IP จะหยุดทันที** |
| 7/7 บันทึก | Google Sheets + CSV สำรอง + สติกเกอร์ + Log → เปลี่ยนชื่อเครื่อง → Restart |

**รอบ Reboot ประจำสัปดาห์:** Task Scheduler → `\SonosLibra\SonosLibra - Weekly Reboot` จะเตือนล่วงหน้า 5 นาที ถ้ากำลังทำงานอยู่ให้ยกเลิกด้วยคำสั่ง `shutdown /a`

## 6. วิธีรีโมทเข้าเครื่องไซต์

1. เปิด **Tailscale** ให้สถานะเป็น Connected
2. เปิด **RustDesk** แล้วกรอก **IP 100.x.x.x ของเครื่องไซต์** ดูได้จากสติกเกอร์, Google Sheets หรือรายการ Devices ใน Tailscale
3. ใส่รหัสผ่าน RustDesk

> ⚠️ **ใช้ IP 100.x เท่านั้น** แม้จะอยู่ในไซต์เดียวกัน IP ของ LAN (192.168.x.x) จะ**ต่อไม่ผ่าน** เพราะตั้งใจบล็อกไว้

| จาก → ไป | ได้ไหม |
|---|---|
| โน้ตบุ๊กของทีม → เครื่องไซต์ไหนก็ได้ | ✅ RustDesk |
| เครื่องไซต์ A → เครื่องไซต์ B (นั่งหน้าเครื่องไซต์แล้วรีโมทต่อ) | ✅ RustDesk |
| โน้ตบุ๊กของทีม ↔ โน้ตบุ๊กของทีม | ✅ |
| เครื่องไซต์ → โน้ตบุ๊กของทีม | ❌ บล็อก |

**ไม่ต้องมีคนกดอะไรที่หน้างาน:**
- เครื่อง Auto-Login เข้าบัญชี `SiteNode` และ RustDesk รันเป็น **Service** ดังนั้นแค่ใส่รหัสผ่าน RustDesk ก็เข้าได้ทันที
- ถ้าเจอหน้าต่าง **UAC (Yes/No)** ระหว่างรีโมท คนที่รีโมทอยู่**กด Yes ผ่าน RustDesk ได้เอง** ไม่ต้องมีคนอยู่หน้าเครื่อง
- ถ้าเจอจอดำตอนมี UAC แปลว่า RustDesk ไม่ได้รันแบบ Service ให้ตรวจว่า Service ชื่อ `RustDesk` เป็น Running / Automatic
- ตรวจครั้งแรกบนเครื่องไซต์: RustDesk → Settings → Security → *Accept sessions via* ต้องรับด้วย **password** ได้ (ไม่ใช่ click อย่างเดียว)

**แถว RESERVED ในชีต:** ตอนเริ่มติดตั้ง ระบบจะจองเลขลำดับเป็นแถว `RESERVED` ไว้ก่อน เมื่อติดตั้งเสร็จจะเขียนข้อมูลจริงทับ ถ้าเห็นแถว RESERVED ค้างนาน แปลว่าการติดตั้งนั้นถูกยกเลิก ลบแถวนั้นทิ้งได้

ทดสอบการเชื่อมต่อ:
```bash
tailscale ping <ชื่อเครื่อง หรือ 100.x>
```
`via <IP>:<port>` = ต่อตรง (เร็ว) / `via DERP` = ผ่าน relay (ใช้ได้แต่ช้ากว่า)

## 7. แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| ดับเบิลคลิก .bat แล้วปิดไปเฉย ๆ | กด No ที่ UAC | รันใหม่แล้วกด Yes |
| "Setup-SiteNode.ps1 not found" | ไฟล์ไม่ได้อยู่โฟลเดอร์เดียวกัน | วางทั้ง 2 ไฟล์ไว้ที่เดียวกัน |
| "เชื่อมต่อ Tailscale ผ่าน HTTPS ไม่ได้" | ไม่มีเน็ต / Captive Portal / Firewall ไซต์ | Login Wi-Fi ผ่าน Browser หรือใช้ Hotspot มือถือ |
| "ติดตั้ง winget ไม่สำเร็จ" (สีเหลือง) | Windows รุ่นเก่า / LTSC / IoT / ปิด App package | ไม่ต้องทำอะไร สคริปต์จะดาวน์โหลด MSI จากเว็บทางการแทนเอง |
| "ไม่มี winget และเชื่อมต่อเว็บดาวน์โหลดทางการไม่ได้" | Firewall ไซต์บล็อก github.com / pkgs.tailscale.com | ใช้ Hotspot มือถือ |
| "ลายเซ็นดิจิทัลไม่ถูกต้อง" | ไฟล์ที่ดาวน์โหลดเสียหาย หรือถูกดักแก้ระหว่างทาง | รันใหม่ ถ้ายังเป็นอยู่ให้แจ้งผู้ดูแล **ห้ามติดตั้งเอง** |
| ระบบให้พิมพ์เลขลำดับเอง | ดึงจาก Google Sheets ไม่ได้ | ดูเลขล่าสุดในชีตแล้วพิมพ์เลขถัดไป |
| "ชื่อสถานที่ยาวได้ไม่เกิน 9 ตัว" | ชื่อเต็มยาวเกิน | ใช้ชื่อย่อ เช่น `CENTRALWORLD` → `CTW` |
| "tailscale up ล้มเหลว" | OAuth key ถูก revoke หรือไม่มีสิทธิ์ tag | ผู้ดูแลตรวจ OAuth client ใน Admin Console |
| ไม่เห็นเครื่องไซต์ใน Tailscale ของโน้ตบุ๊ก | ไม่ได้ login บัญชีทีม หรือ ACL ไม่ตรงกับไฟล์ | Login บัญชีทีม / ตรวจ ACL |
| RustDesk ต่อไม่ผ่าน | ใช้ IP ของ LAN หรือ Tailscale ปิดอยู่ | ใช้ 100.x และเปิด Tailscale |
| หลัง Restart ค้างที่หน้า Login | รหัส `SiteNode` ไม่ตรงกับ Auto-Login | รันสคริปต์ซ้ำ (จะตั้งรหัสใหม่ให้) |
| เครื่อง Restart เองตอนตี 4 วันอาทิตย์ | รอบ Reboot ประจำสัปดาห์ (ตั้งใจไว้) | ยกเลิกครั้งนั้นด้วย `shutdown /a` |

**ดู Log:** `USB\Logs\` หรือรีโมทเข้าไปดูที่ `C:\ProgramData\SonosLibra\Logs\`

## 8. กฎการแก้ไขไฟล์ (สำคัญ)

| ไฟล์ | Encoding | บรรทัด | หมายเหตุ |
|---|---|---|---|
| `Setup-SiteNode.ps1` | **UTF-8 with BOM** | CRLF | ถ้าไม่มี BOM ภาษาไทยจะเพี้ยนบน PowerShell 5.1 |
| `Install-SiteNode.bat` | ASCII / UTF-8 **ไม่มี BOM** | CRLF | **ห้ามใส่ภาษาไทย** |

- `.vscode/settings.json` และ `.gitattributes` ในชุดนี้ตั้งค่าให้อัตโนมัติแล้ว

- เปลี่ยน `$ScriptVersion` และเพิ่ม Changelog ทุกครั้งที่แก้
- เก็บใน Git ได้เฉพาะ **private repository** เท่านั้น

> ผู้รับผิดชอบระบบรับทราบและยอมรับความเสี่ยง R1–R4 แล้ว เพื่อให้การทำงานของทีมง่ายขึ้น (บันทึกเมื่อ 2026-11-08)

| # | รายการ | หมายเหตุ |
|---|---|---|
| R1 | รหัสผ่านเดียวทุกไซต์ (`SiteNode` + RustDesk) | รู้เฉพาะผู้รับผิดชอบโดยตรง |
| R2 | Tailscale OAuth key ฝังในสคริปต์ | จำกัด scope ไว้ที่ Auth Keys เพื่อลดความเสียหายถ้า USB หาย |
| R3 | เครื่องไซต์รีโมท RustDesk หากันได้ | ทำงานหน้างานสะดวก |
| R4 | ใช้บัญชี GitHub ของทีมร่วมกัน | `engineering@` เป็น group email ไม่ใช่ mailbox |

**ถ้า USB หาย หรือมีคนออกจากทีม:**
1. Revoke OAuth client แล้วสร้างใหม่ จากนั้นแก้ `$TailscaleKey` ในสคริปต์
2. เปลี่ยนรหัส GitHub ของทีม แล้วลบเครื่องของคนที่ออกใน Machines
3. พิจารณาเปลี่ยน `$MasterPassword` แล้วรันสคริปต์ซ้ำทุกไซต์ผ่านรีโมท
